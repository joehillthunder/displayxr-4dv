Spatial UI/UX4D Volumetric Viewer

Volumetric video from 4DV.ai, played in glasses-free 3D on a Leia display. People and scenes are captured as moving 3D Gaussian splats, so you can lean in and look around them while they play.

Download for Windows Source on GitHub

Unlike most DisplayXR HQ demos, this one is a Windows app, not a web page: 4DV.ai's player ships as a Unity plugin. Without a 3D display it still runs, in 2D in a normal window.

Run it

  1. Install DisplayXR with the DisplayXR installer (runtime, Shell and Leia SR plug-in).
  2. Download 4DV-Viewer-Win64.zip from the latest release (1.9 GB: the app and 8 clips) and unzip it anywhere. For more clips, also download Clips-Pack2 (badminton, Neemo, Unitree robot, wedding) and Clips-Pack3 (horse, corridor interview) and unzip them into the same folder.
  3. Run 4DV Viewer.exe. It opens in a window and weaves 3D inside it; the clip plays and loops. Drag to walk around the performer.

Controls

The sidebar lists every clip and has play/pause, previous/next, a seekable progress bar, loop mode, speed, 3D on/off, turntable, reset view and a 3D strength slider. Clips with a soundtrack play it in sync.

What it's for

Demo
Show volumetric video at events: a performer or a talking head you can walk around, without a headset.
Quality check
4DV.ai says its own plugin renders better than other players. This app uses that plugin unchanged, so it's the reference to compare against the DisplayXR splat viewer.

More clips

The release includes a selection from 4DV.ai's sample library: dance, sport, interviews, a horse, a cat, a robot and more. The library has more than 20 clips; others can be converted with one command, as the README explains.
